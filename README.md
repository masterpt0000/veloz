# Veloz

High-performance chart + strategy workspace (TradingView-like). Candlestick charts via TradingView Lightweight Charts, in-browser JavaScript/TypeScript strategy editor, Web Worker backtests, and bundled sample market data.

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`. Edit the strategy, click **Executar backtest**.
